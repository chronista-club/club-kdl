# 03. 原文を保持した値の編集

**[English](./03-preserve-value-edits.md)** | 日本語

> **Status**: Draft
> **関連**: design 04、`mem_1CggW2QewS8jT8ejr6jRC6`
> **対象**: `src/edit.rs`, `tests/preserve_edits.rs`

## 目的

ユーザーのコメントを失ったり周囲の文書を書き直したりせずに、アプリケーションから
既存の KDL 値を変更できるようにする。明示的に選択する編集用 API とし、既存の意味ツリーと
整形して書き出すシリアライザーの動作は維持する。

## 範囲と要件

- `edit` Cargo feature で `edit::EditableDocument` を公開する。原文を所有し、KDL v2 として
  検証する。新しい依存は追加しない。
- 未編集の文書は、コメント・BOM・改行・空白・値の表記を含め、すべての入力バイトを保持する。
- 空でないノード index のスライスで対象を指定する。各段は 0 始まりで、子ノードへ降りる。
  有効なノードだけを数え、`/-` で無効化されたノードは数えない。
- `set_argument(path, index, value)` は既存の位置引数を更新する。引数 index にプロパティは
  数えない。`set_property(path, name, value)` は、通常の参照と同じく、指定した名前を持つ
  有効なプロパティのうち右端のものを更新する。
- 指定した値トークンだけを変更する。プロパティのキー、型注釈、周囲のすべてのバイトは保持する。
  置換する値は既存の KDL v2 writer で書き、引用符とエスケープも扱う。同じ意味の値を設定しても、
  対象トークンの表記は正規化されることがある。型注釈に対するスキーマ検証は行わない。
- ノード・引数・プロパティが存在しなければエラーにする。空のノードパスもエラーにする。
  失敗した編集では原文を変更しない。成功後は、値のバイト長が変わっても続けて編集できる。
- `/-` で無効化された entry と子ブロックは原文のまま保持し、編集対象にしない。

最初の版では、ノード・entry の追加・削除・移動、構造体から元文書への自動反映、複数ファイル
合成の書き戻し、ファイル入出力は扱わない。編集のたびに現在の文書を走査し、差分解析は行わない。

## 検証

コメント、型注釈、UTF-8、raw・複数行文字列、CRLF、`/-`、名前・プロパティの重複、連続編集、
失敗時の不変性を、テキストの完全一致で確認する。KDL 仕様コーパスで、原文保持・指定した値の
更新・再解析後の意味を確認する。既存パーサー・writer のテストと変更前後のベンチマークで、
通常の経路も検証する。
